# Agent workflow implementation for A Research Idea Novelty Score
## Description
Through an interactive multi-agent flow that presses the researchers to evvaluate the literature review using layman terms before starting off to search the arXiv or any other research publication / platform.

## Core Modules Used: 
Streamlit, Langchain, LangGraph

## How to Run
`streamlit run source.py`

No other dependencies are required to be explicitely installed if you have a conda package manager.
Else install all the dependencies in your own venv using

`pip install requests streamlit pydantic langchain-core langchain-groq langgraph`
